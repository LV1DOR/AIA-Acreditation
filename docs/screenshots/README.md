# README screenshots

These images show the application's actual administration components and styles, rendered offline with fictional event, company, worker and request data. They are documentation examples, not captures of a live event or evidence of a production acceptance test.

Pages: Companies, People, Submissions, Requests and Exports. The interface is in Portuguese. Names marked “exemplo”, `example.test` email addresses and the demonstration event are synthetic.

The renderer uses `AdminAreaView`, `PortalShell`, the navigation components and compiled application CSS from source commit `21f6b11399e8cbf8a5d5711e700971797603e498`. Authentication, data loaders, server actions, realtime connections and framework navigation are substituted for offline rendering. No production database, account, photo storage or email service is accessed. Browser capture runs with networking disabled.

Update these images when the corresponding screens change. Keep demonstration data in documentation images; do not replace them with unredacted live records.
