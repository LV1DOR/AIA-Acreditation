# Leader portal UI reference

The visual references supplied in the project conversation on 23 September 2026 define the intended company-leader portal language:

- white AIA navigation rail with bilingual labels;
- compact black line icons and AIA red active states;
- a dark event banner with event dates and venue;
- bilingual headings and supporting labels;
- restrained cards, status colours and strong red/black actions;
- overview, workers, final-submission and requests layouts.

The original chat images are not exposed to the repository as downloadable files. Add the original image files to this folder when they are supplied as attachments; do not replace them with regenerated or recompressed copies. Current implementation work follows the images shown in the conversation while preserving future-phase boundaries.
