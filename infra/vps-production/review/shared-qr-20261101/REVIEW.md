# Shared export QR release

Review of upstream f867cad: both workbooks encode the existing event-participant UUID's 16 bytes as standard Base64, producing the same 24-character text for the same participant. No new identifier storage, data mutation, migration, dependency or credential. Existing approved-attendee selection, admin authorization, photo/history checks, private download/no-cache rules and scratch cleanup remain unchanged. The QR is an identifier, not authentication or signed access authorization. WeBook acceptance of AIA-generated codes remains an operator integration decision before operational scanner use; the update does not claim that acceptance.

Focused synthetic tests verify known bytes, invalid input, distinct IDs, normalization, both spreadsheet formats and repeated downloads. Existing invitation, export/archive, privacy, worker email and type checks run in the existing offline PC harness; isolated PostgreSQL covers history/access regressions. No production records, real invitations or email are used by these tests.

External serial web/worker/tools rebuild preserves matching-source immutable release contract and reviewed AIStor maintenance client. Deployment requires explicit approval, verified image/source proofs, original 8 GB capacity gate, fresh encrypted backup, web/worker replacement only and public/private TLS readiness.
